01 — Roteiro falado

Cole a fala original. O separador sugere cenas sem reescrever o texto.

02 — Referências visuais

Adicione fotos para manter as referências à mão durante a preparação do prompt. As imagens ficam apenas neste navegador enquanto a página estiver aberta; não são enviadas ao Google Flow por este protótipo.

Escolha a foto da modelo, do produto ou do cenário.

Dica: no Flow, anexe manualmente as imagens de referência compatíveis com o recurso escolhido. Este aplicativo ainda não controla sua conta do Google.

03 — Direção de movimentos

Descreva uma ação por vez, na ordem em que deve acontecer.

04 — Construtor de prompt para Flow

Gera um prompt estruturado a partir dos dados preenchidos. Revise cada cena antes de copiar.

O prompt não gera o vídeo sozinho. Copie-o para o Flow e anexe as imagens de referência diretamente na ferramenta.

Como testar sem desperdiçar créditos

  1. Teste uma ação principal por clipe.
  2. Use uma imagem de referência nítida.
  3. Compare o resultado com o movimento solicitado.
  4. Corrija uma variável por vez.
  5. Guarde o prompt que funcionou.
